1. Overview

Sigapan adalah sistem informasi pemantauan harga dan stok bahan pokok di pasar-pasar di wilayah Bantul. Sistem ini melibatkan 3 aktor utama dengan alur kerja terintegrasi.

Lurah bertanggung jawab menginput harga komoditas di pasar yang menjadi wilayahnya. Setiap Lurah di-assign ke satu pasar.

Alur Input Harga oleh Lurah

sequenceDiagram
    participant L as Lurah
    participant S as Sistem
    participant DB as Database
    participant A as Admin
    L->>S: Login
    S->>L: Dashboard (statistik pasar)
    L->>S: Buka halaman Komoditas
    S->>L: Daftar komoditas + harga terakhir
    L->>S: Update harga komoditas
    S->>DB: Simpan (status=draft)
    S->>L: Menunggu verifikasi admin
    Note over DB: Draft TIDAK tampil di publik
    A->>S: Review dan Publish
    S->>DB: Update status → verified
    Note over DB: Verified TAMPIL di publik
⚠️ Penting Semua input harga dari Lurah otomatis berstatus draft. Data draft tidak akan tampil di halaman publik sampai Admin melakukan Publish/Verify.

Alur Admin — Tambah Komoditas Baru

sequenceDiagram
    participant A as Admin
    participant S as Sistem
    participant DB as Database
    A->>S: Klik Tambah Komoditas
    A->>S: Isi nama, satuan, harga acuan, kategori
    S->>DB: Insert ke tabel komoditas
    loop Setiap Pasar Monitored
        S->>DB: Cek record hari ini
        alt Ada record hari ini
            S->>DB: Tambahkan ke data_harga
        else Belum ada
            S->>DB: Buat record baru + copy data terakhir
        end
    end
    S->>A: Komoditas berhasil ditambahkan

5. Data Model

Entity Relationship

erDiagram
    PASAR {
        int id PK
        string nama_pasar
        string slug
        boolean is_active
        boolean is_monitored
    }
    KOMODITAS {
        int id PK
        string nama_komoditas
        string satuan
        decimal harga_acuan
        int kategori_id FK
        boolean is_active
    }
    HARGA_BAPOK_HARIAN {
        int id PK
        int id_pasar FK
        date tanggal
        json data_harga
        string status
        int created_by FK
        int verified_by FK
    }
    KATEGORI_KOMODITAS {
        int id PK
        string nama_kategori
    }
    PASAR ||--o{ HARGA_BAPOK_HARIAN : "has many"
    KATEGORI_KOMODITAS ||--o{ KOMODITAS : "has many"

Struktur JSON data_harga

{
  "1": {
    "harga": 35000,
    "tanggal": "2026-02-14",
    "status": "verified"
  },
  "2": {
    "harga": 37000,
    "tanggal": "2026-02-14",
    "status": "verified"
  }
}
  • Key: komoditas.id
  • harga: Harga dalam Rupiah
  • tanggal: Tanggal update terakhir komoditas spesifik ini
  • status: draft atau verified
📝 Catatan Field tanggal di dalam JSON berbeda dari kolom tanggal di tabel. Field JSON menunjukkan kapan komoditas spesifik terakhir diupdate, sedangkan kolom tabel menunjukkan tanggal record keseluruhan.

Aturan Tampil Data

RuleKeterangan
Hanya verifiedSemua halaman publik hanya menampilkan data berstatus verified
Harga > 0Sigapan Home menyembunyikan komoditas dengan harga 0
Tanggal cocokTabel Harga hanya tampil jika tanggal update komoditas = tanggal record
Pasar monitoredLanding pages hanya menampilkan pasar dengan is_monitored = true
